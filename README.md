# CareerPath

## Deskripsi

CareerPath adalah platform berbasis web yang dirancang untuk membantu mahasiswa dan pencari kerja dalam menemukan lowongan pekerjaan atau magang yang sesuai dengan minat dan keterampilan mereka. Platform ini menyediakan fitur pencarian lowongan, melihat detail pekerjaan, mengelola lamaran, serta mengelola profil pengguna.

## Tujuan Project

CareerPath bertujuan untuk membantu mahasiswa dan pencari kerja menemukan informasi lowongan pekerjaan atau magang secara lebih mudah dan terstruktur. Project ini dibuat untuk mengatasi kesulitan pengguna dalam mencari lowongan yang sesuai dengan keterampilan, minat, dan kebutuhan mereka.

## Fitur Awal

- Pencarian lowongan pekerjaan dan magang
- Melihat detail lowongan
- Pengelolaan lamaran
- Profil pengguna
- Dashboard
- Login dan logout
- Pengaturan pengguna
