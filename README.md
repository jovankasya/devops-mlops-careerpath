CareerPath

## Deskripsi
CareerPath adalah platform berbasis web yang dirancang untuk membantu mahasiswa dan pencari kerja menemukan informasi lowongan pekerjaan atau magang sesuai dengan minat dan keterampilan mereka. Website ini menyediakan halaman beranda, dashboard, pencarian lowongan, detail pekerjaan, pengelolaan lamaran, profil pengguna, dan pengaturan.

Project ini dikembangkan secara bertahap dengan memanfaatkan website CareerPath yang sudah ada. Pengembangan selanjutnya berfokus pada penyempurnaan fungsi website, penerapan DevOps untuk pengelolaan kode dan pengujian otomatis, serta eksplorasi Machine Learning dan MLOps sederhana sesuai kebutuhan project.

## Tujuan Project
1. Menyediakan platform pencarian lowongan pekerjaan dan magang yang mudah digunakan.
2. Menyempurnakan fungsi utama website, seperti login, logout, dan pencarian lowongan.
3. Menerapkan Git dan GitHub untuk pengelolaan kode serta kolaborasi kelompok.
4. Mempelajari penerapan DevOps melalui pengujian otomatis dan Continuous Integration.
5. Mengeksplorasi Machine Learning sederhana untuk klasifikasi kategori lowongan pekerjaan.
6. Mempelajari konsep MLOps dasar untuk pengelolaan dan pengujian model Machine Learning.

## Fitur Awal

- Beranda: menampilkan halaman utama CareerPath.
- Login dan Logout: menyediakan halaman masuk dan keluar pengguna.
- Dashboard: menampilkan halaman utama aktivitas pengguna.
- Pencarian Lowongan: menampilkan dan membantu pengguna mencari lowongan pekerjaan atau magang.
- Detail Lowongan: menampilkan informasi mengenai posisi dan persyaratan pekerjaan.
- Lamaran Saya: menyediakan halaman untuk melihat informasi lamaran.
- Profil Pengguna: menampilkan informasi profil pengguna.
- Pengaturan: menyediakan halaman pengaturan pengguna.

Fitur-fitur tersebut akan diperiksa dan disempurnakan secara bertahap. Keberadaan halaman tidak selalu berarti seluruh fungsi backend sudah berjalan.

## Technology Stack

### Teknologi yang Digunakan Saat Ini

- PHP: bahasa pemrograman untuk halaman website dan pemrosesan sisi server.
- HTML5: menyusun struktur halaman website.
- CSS3: mengatur tampilan dan tata letak website.
- JavaScript: mendukung interaksi pada halaman website.
- Google Fonts (Poppins): menyediakan jenis huruf untuk antarmuka.
- Font Awesome 6.4.0: menyediakan ikon untuk antarmuka website.

### Teknologi untuk Pengembangan Selanjutnya
- Git dan GitHub: pengelolaan versi kode dan kolaborasi kelompok.
- GitHub Actions: rencana otomatisasi pemeriksaan dan pengujian kode.
- MySQL: rencana penyimpanan data pengguna, lowongan, dan lamaran jika dibutuhkan.
- Python dan scikit-learn: rencana pengembangan model Machine Learning sederhana.
- Docker: opsi untuk menjalankan website dalam lingkungan yang konsisten.

Teknologi pada bagian pengembangan selanjutnya akan diterapkan secara bertahap sesuai kebutuhan dan target project.
