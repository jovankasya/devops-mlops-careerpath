# Rencana Pengembangan Project CareerPath

## Tujuan

Dokumen ini berisi rencana pengembangan awal website CareerPath pada mata kuliah DevOps & MLOps.

## Rencana Pengembangan

Pengembangan CareerPath akan dilakukan secara bertahap dengan fokus pada penyempurnaan fitur yang sudah tersedia dan penerapan konsep DevOps serta MLOps sesuai kebutuhan project.

Tahap awal pengembangan meliputi:

1. Memeriksa fungsi utama website CareerPath.
2. Memeriksa fungsi detail lowongan pekerjaan.
3. Menyempurnakan fungsi website apabila ditemukan masalah.
4. Menambahkan dokumentasi hasil pengembangan dan pengujian.
5. Menerapkan pengujian otomatis secara bertahap.
6. Mempelajari penerapan Continuous Integration menggunakan GitHub Actions.
7. Melakukan deployment website.
8. Mengeksplorasi penerapan Machine Learning sederhana apabila sesuai dengan kebutuhan project.

## Kesimpulan

Pengembangan CareerPath akan dilakukan secara bertahap selama satu semester dengan menggunakan GitHub sebagai media kolaborasi dan pengelolaan source code.
