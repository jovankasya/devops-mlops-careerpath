# Rencana Pengujian CareerPath

## Tujuan

Dokumen ini berisi rencana pengujian awal terhadap fitur utama website CareerPath.

## Fitur yang Akan Diuji

### 1. Login

Memastikan pengguna dapat masuk ke sistem menggunakan data akun yang valid.

### 2. Logout

Memastikan pengguna dapat keluar dari sistem dan session pengguna berakhir dengan benar.

### 3. Dashboard

Memastikan halaman dashboard dapat diakses setelah pengguna berhasil login.

### 4. Navigasi

Memastikan perpindahan antarhalaman pada website dapat berjalan dengan baik.

### 5. Pencarian Lowongan

Memastikan fitur pencarian dan informasi lowongan dapat ditampilkan dengan baik.

## Hasil yang Diharapkan

Setiap fitur utama dapat berjalan sesuai dengan fungsinya dan tidak ditemukan kesalahan yang mengganggu penggunaan website.
